# Composio Connect Link Integration

Status: implemented for manual account authorization.

Nomi uses Composio as an external tool execution layer, but Composio does not own Nomi's routing, confirmation, or audit policy. The first version uses manual Connect Links:

1. Nomi creates or reuses a Composio session for `COMPOSIO_USER_ID`.
2. Nomi restricts sessions by toolkit allowlist and tags.
3. The user clicks a Connect Link generated by `session.authorize(toolkit_slug)`.
4. Nomi records the request locally and syncs connection status through `session.toolkits()`.

## Session Policy

Readonly sessions:

- toolkits: `COMPOSIO_READONLY_TOOLKITS`
- tags: enable `readOnlyHint`, disable `destructiveHint`
- purpose: search, summarize, read Gmail/Calendar/Drive/Docs/Sheets/Tasks/Maps and other connected sources.

Write sessions:

- toolkits: `COMPOSIO_WRITE_TOOLKITS`
- tags: disable `destructiveHint`
- purpose: confirmed write actions such as draft/send email, create calendar task, create issue, or update Notion.

High-risk purchase, payment, transfer, destructive delete, and irreversible booking actions remain outside normal sessions.

## API Surface

- `GET /api/integrations/composio/status`
- `POST /api/integrations/composio/connect/{toolkit_slug}`
- `GET /api/integrations/composio/toolkits?session_kind=readonly`

Responses redact MCP headers and never return `COMPOSIO_API_KEY`.

## Local Tables

- `composio_sessions`
- `composio_connect_requests`
- `composio_toolkits`
- `composio_tool_invocations`
- `composio_triggers`

`account_connections` is also updated when a Connect Link is created.

## Verification

Behavior is covered by tests that check:

- missing `COMPOSIO_API_KEY` returns a clear 503 and does not create an SDK client
- Connect Link generation uses `manage_connections=False`, an allowlisted session, and a `destructiveHint` block
- API responses include the redirect URL and session identity while redacting MCP headers and the API key
- toolkit sync reports connected account status and stores local toolkit rows
