# Nomi Web 侧栏紧凑上移设计

## 目标

桌面端工作台左侧栏中的功能导航应从品牌区下方开始连续排列，消除当前由上下两端分布造成的大块无意义空白，使首屏功能更容易扫描和点击。

## 范围

- 仅调整桌面端 `.sidebar` 的纵向布局和品牌区与导航区之间的间距。
- 保持 Nomi 品牌、功能名称、功能顺序、选中状态和导航行为不变。
- 保持移动端现有顶部工具栏与设置面板行为不变。

## 方案

- 将侧栏主轴分布从 `space-between` 改为从顶部连续排列。
- 在品牌区与导航区之间设置稳定的紧凑间距，避免元素贴合，也避免随屏幕高度被拉散。
- 侧栏高度不足时允许纵向滚动，保证较小桌面窗口下所有入口仍可访问。

## 验收标准

1. 桌面宽度下，`对话`入口位于品牌说明下方，不再贴近页面中部。
2. 全部导航项保持原顺序且可见、可点击。
3. 侧栏较矮时可以纵向滚动，功能项不被裁切。
4. 移动端断点下侧栏仍隐藏，不影响现有移动端布局。
5. 静态布局测试和现有工作台相关测试通过。
