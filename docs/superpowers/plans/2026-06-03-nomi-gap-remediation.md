# Nomi Gap Remediation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the current product gaps between Nomi's implemented code and the private personal assistant requirements, with explicit evidence for every completed item.

**Architecture:** Keep the existing local/private-cloud architecture. Close gaps incrementally by adding tests first, then implementation, then a reasonableness check that inspects actual outputs instead of only exit codes.

**Tech Stack:** FastAPI runtime API, PostgreSQL/pgvector, Redis, Chromium runtime collectors, Python worker, Android Java floating assistant, Composio sessions/toolkits, OpenClaw long-tail runtime.

---

## Scope Rules

- In scope: current Nomi private-cloud assistant, Android floating assistant, browser collectors, memory, agenda, suggestions, pipeline routing, Composio/OpenClaw integration, online regression.
- Out of scope for this pass: iOS, local model deployment, Android launcher mode.
- Every item must record one of: `pending`, `in_progress`, `verified`, `verified_with_gap`, or `blocked`.
- A feature is not `verified` unless the actual output has been inspected for correctness and reasonableness.

## Verification Contract

For each gap:

1. Write or update a test that fails before the implementation.
2. Run the focused test and confirm the failure reason matches the gap.
3. Implement the smallest change that closes the gap.
4. Run the focused test again and inspect the output.
5. If relevant, run a higher-level smoke or regression command.
6. Update this document with status and any remaining risk.
