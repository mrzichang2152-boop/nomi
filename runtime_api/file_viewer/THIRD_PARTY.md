# Third-party viewer assets

Nomi includes selected browser assets from `@file-viewer/web-full` version `2.1.29`, maintained by the Flyfish File Viewer project.

- Project: https://github.com/flyfish-dev/file-viewer
- License: Apache License 2.0

Only the image, PDF, Word, presentation, spreadsheet and text renderers and their required offline worker/vendor resources are included in the Nomi runtime image.
